## 📝 소개  

책(Book)을 사랑하는 사람들이 **북적북적**이며 이용하는 플랫폼  

신규 및 중고 도서 리스트를 쉽고 빠르게 확인 & 구매 가능  


📌 **Demo**: http://43.203.108.179/  

🧾 **Swagger API 문서**: https://oeoroeor123.github.io/swagger-docs/

<br />

## 🔍 주요 기능  

📘 도서 리스팅 / 검색 / 상세 페이지 확인 가능  

📌 카테고리별 정렬 및 필터링  

💬 도서 상품 문의 / 후기 확인 가능  

🛒 관심 도서 찜 기능  

✅ 실시간 거래 상태(판매중 / 예약중 / 판매완료) 표시 및 변경  

🔐 JWT 기반 로그인 / 회원가입 / 인증처리  

<br />

## ⚙ 기술 스택  

**Spring Tool Suite 4:**  
Java & Spring 기반 백엔드 개발에 사용, JPA와 REST API 개발 중심  

**Visual Studio Code:**  
React 기반 프론트엔드 개발에 사용  

**MobaXterm:**  
Docker 컨테이너로 애플리케이션 패키징 후 AWS EC2 인스턴스에 배포
